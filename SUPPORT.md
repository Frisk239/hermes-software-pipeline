# Support

Hermes Software Pipeline is in design/foundation status. There is no runnable product, supported installation, compatibility guarantee, migration path, or operational SLA yet.

## Where to ask

Use the repository's GitHub Discussions or issue tracker for:

- documentation questions;
- Phase 00 development questions;
- reproducible design inconsistencies;
- feature proposals that do not contain sensitive information.

The repository is `Frisk239/hermes-software-pipeline`. Use its GitHub Discussions or issue tracker once those features are enabled.

## What to include

Provide:

- the exact commit SHA or state that you inspected;
- operating system and relevant tool versions;
- the governing document, ADR, Schema, or command;
- expected and observed behavior;
- minimal non-sensitive reproduction information.

Do not include credentials, private Project source, raw model transcripts, proprietary artifacts, or sensitive logs.

## Security and private data

Suspected vulnerabilities follow `SECURITY.md`, not public support channels. Questions involving private repositories or artifacts should be reduced to a synthetic fixture before sharing.

## Current support boundary

Until a public-preview release:

- design and documentation feedback are welcome;
- installation and runtime behavior are unsupported;
- no compatibility promise exists beyond the targets recorded for Phase 00 feasibility;
- the Repository Governance Owner may close requests that require unapproved product scope, unsafe authority, or unavailable external infrastructure.
