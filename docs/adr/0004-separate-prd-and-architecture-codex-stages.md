# Separate PRD and Architecture into independent Codex Stages

The PRD and Architecture responsibilities run as separate Pipeline Stages in fresh Codex sessions. Architecture consumes the current PRD attempt as an upstream artifact and may raise an evidence-backed Requirement Question for human routing but cannot itself rewrite product intent or select the rework destination, accepting the additional model cost in exchange for independent scrutiny, explicit handoff evidence, and a recoverable boundary before implementation.
