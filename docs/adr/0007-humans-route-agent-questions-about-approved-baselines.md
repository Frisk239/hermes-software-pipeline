# Let Agents question baselines but let humans route the answer

A downstream Agent may raise an evidence-backed question about an approved baseline but may neither invalidate that baseline nor choose the rework destination. The human responsible for the challenged baseline decides whether to send the decision to the upstream authoring role for a new approved attempt, return an authoritative direction to the questioning role, or keep the Pipeline waiting for further discussion; every outcome is preserved as a first-class decision rather than a chat summary.
