# Isolate Project content from Workspace governance

Project membership is explicit and is not inherited from Workspace membership or the Workspace Administrator role. Workspace Administrators govern identities, Project registration, global policy, quotas, health, and recovery using cross-Project operational metadata, but must join a Project explicitly to read its requirements, source-related artifacts, logs, or reports; normal access admission remains under the Project Administrator, with Workspace intervention reserved for audited recovery of an orphaned Project.
